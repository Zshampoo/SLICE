# dataset

Shared constants and split helpers used by **SIE** / **PCR** / **ECG**.

- `constants.py` — anatomical region names and related enums  

Dataset **images and annotations are not shipped**. See the root README **Data & weights** section for MIMIC-CXR-JPG, Chest ImaGenome, CheXpert Plus, and ReXGradient download links, plus Train-SIE / Train-ECG / Val / Test statistics.
